සාමාන්‍ය blockchains වල ඔබේ balance එකයි transactions ටිකයි ඕන කෙනෙකුට බලන්න පුළුවන්. Hackers ලා ඒ data පාවිච්චි කරලා ඉලක්ක හොයනවා. Midnight Foundation CTO Sebastien Guillemot කියන්නේ privacy කියන්නේ security එකක් කියලා.

🎯 Privacy අඩු කරන අවදානම්

  • Whale watching සහ phishing: ලොකු balances පේන්නේ නැති නිසා ඉලක්ක හොයන්න අමාරුයි, විශ්වාස කරන්න පුළුවන් scam messages හදන්නත් අමාරුයි.
  • Wallet profiling: ඔබ මොනවද තියාගෙන ඉන්නේ, කාත් එක්කද ගනුදෙනු කරන්නේ කියලා chain එක scan කරලා හොයන්න බෑ.
  • Hash guessing: Balance එක hash කරන්න කලින් random secret එකක් එකතු කරන නිසා hackers ලට අනුමාන කරලා match කරන්න බෑ.

🔐 සරලව තේරුම් ගමු

  • Note commitment: ඔබේ coin එකේ on-chain සටහන. පිටින් බලන කෙනෙකුට පේන්නේ random අකුරු පෙළක් විතරයි.
  • Nullifier: coin එක වියදම් කළාම publish වෙන අගයක්. එකම coin එක දෙපාරක් වියදම් කරන එක (double-spend) නවත්වනවා, ඒත් ඒකෙන් ආපස්සට ඔබව හොයන්න බෑ.
  • ZK proof: coin එක ඔබේ බව prove කරනවා, මොන coin එකද, කීයද, ඔබ කවුද කියලා නොකියා.
  • Viewing key: ඔබට ලැබෙන payments විතරක් බලන්න පුළුවන් key එකක්. ඒකෙන් spend කරන්න බෑ.

⚠️ ඔබට tips

  • Viewing key එක password එකක් වගේ රකින්න. විශ්වාස කරන අයට විතරක් දෙන්න.
  • Wallet එක connect කරන්න විශ්වාස කරන DApps වලට විතරයි.
