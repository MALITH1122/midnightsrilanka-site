නොවැම්බර් 6 Midnight mainnet එක Ledger 8 සිට Ledger 9 ට hard fork එකක් හරහා upgrade වුණා. Developers ලට සහ institutions ලට මේක ලොකු පියවරක්.

✨ අලුත් features

  • Signature support: Compact එකට Keccak-256 සහ ECDSA ආවා. මධ්‍යම තැනක් නැතුව වෙනත් chains වල assets Midnight එකට ගේන්න පුළුවන්.
  • Custody support: BIP-44 නිසා custodians ලට දැනට තියෙන software එකෙන්ම Midnight wallets හදන්න පුළුවන් (උදා: BitGo).
  • Cross-contract calls: approve, swap, deposit වගේ පියවර කිහිපයක් එක click එකකින්.
  • Caller check: කවුද call කළේ කියලා contract එකට බලන්න පුළුවන්. උදා: withdraw කරන්න අවසර දෙන්නේ approved contract එකකට විතරයි.
  • Events: transaction එක ඉවර වුණාම wallets සහ explorers ලට real-time update වෙන්න පුළුවන්.
  • ZKIR V3 proof format, performance සහ security fixes.

👤 Users ලට කරන්න ඕන මොකක්ද?

  • Mainnet: කිසිම දෙයක් නෑ. Balances සහ DUST registration ඉබේම migrate වුණා.
  • Preview / Preprod: DUST generation ආයෙ පටන් ගන්න tNIGHT re-register කරන්න ඕන.

👩‍💻 Developers ලට

  • Deploy කරපු contracts වෙනස් වෙන්නේ නෑ, ඒත් apps Midnight.js 5 ට update කරන්න ඕන.
  • අලුත් contracts Ledger 9 ට අලුත් Compact toolchain එකෙන් compile කරන්න.
